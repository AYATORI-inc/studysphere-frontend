### 8-2. 調査で分かったこと

- **週次評価の AI 生成が 500**: 本文は汎用メッセージのみ。フロントの送信項目、DB のカラム、モデル指定（`AI_MODEL`）はコード上で問題なし。バックエンドへの依頼文を作成し、バックエンド側で解消済み（ユーザー報告）
- **月次評価（達成度評価）の AI 生成が 500**（`/api/monthly-evaluation-ai/generate-goal`）: 推定原因は、バックエンドの `routes/monthlyEvaluationAIAssistRoutes.js` で `max_tokens` が 300〜400 と小さく、推論モデルが推論で上限を使い切って本文が `null` になり、`.trim()` で TypeError になること（学習画面の解説 API と同じ型）。ログでは未確認
  - 同じ書き方のルートが 7 つある（`generate-goal` / `effort` / `achievement` / `issues` / `improvement` / `health` / `appropriateness`）。フロントは 7 つを順番に呼び、1 つでも 500 だと以降が止まる
  - 修正案（推論の無効化、`max_tokens` の増加、空応答時の再試行）を含む依頼文を作成済み。フロントの修正は不要
- **学習画面でセクションが表示されない**（コース 3・レッスン 21 の「C3 2 1」）: バックエンドの `GET /api/lesson-text-video-links/lesson/:lessonId` は、既定で動画（`video_id`）が紐づいたセクションしか返さない（`includeNoVideo=true` で動画なしも含む）。フロントはこのパラメータを付けていないため、動画なしのセクションは出ない。紐づけが別の `lesson_id` に登録されている可能性もある
  - 確認方法: Network タブで上記 API の応答を見る。無ければ DB で `lesson_text_video_links`（`lesson_id = 21`）と `lesson_text_files` を確認
- **在宅支援の「在宅における就労支援記録」ポップアップの AI 提案ボタンの活性条件**（すべて生成中は無効）
