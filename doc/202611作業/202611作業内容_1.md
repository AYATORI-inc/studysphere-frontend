# 2026年11月の作業内容

2026-11-19 に、ここまでのフロントエンドを本番へ反映した。成果物は `build/static/js/main.1b187623.js`。APIの向き先は `https://studysphere-backend.ayatori-inc.co.jp`。バックエンドのコードは変えていない。

## 指導員ダッシュボード

在宅のカードを、学習と同じ幅で並べた。拠点と設定は、在宅のうしろに出る。

在宅のカードは次の順。

| カード | 開く場所 |
|---|---|
| 今日の在宅状況 | 在宅の今日 |
| 利用履歴 | 在宅の利用履歴 |
| 評価記録 | 評価記録。日次未記載、週次未記載、達成度未実施の件数をカードに出す |
| 在宅利用者情報 | 在宅利用者 |
| 写真履歴 | 在宅の記録タブ |
| 勤怠管理 | 在宅の勤怠管理タブ |
| 旧ダッシュボード | 在宅の概要タブ（`/instructor/home-support`） |

評価記録の画面にも、日次未記載、週次未記載、達成度未実施の一覧を出した。この画面の支援記録ボタンは外した。達成度評価は「達成度評価(月次)」、過去の記録確認は「就労支援記録出力」、達成度履歴確認は「月次評価シート出力」にした。出力先はこれまでと同じ。

週次評価、月次評価、月次評価シート、就労支援記録の各画面は、他の画面と同じヘッダーにした。ヘッダーの「戻る」は外した。記録が無いときの戻るボタンは残している。

## 利用履歴

本人記録は、未開始でも開ける。打刻の修正、コメントの追加と削除ができる。支援記録は、未開始のあいだは押せない。日次記録の削除を置いた。一覧の修正ボタンは外した。勤怠管理の修正はそのまま。

その日の記録が無い利用者は、指導員が下書きを作れる。バックエンドへの依頼は `doc/202611作業/202611バックエンドあて依頼/利用履歴_日次記録の新規作成.md`。

## 打刻の時刻

本番を確認した。ホストは日本時間。Node と MySQL のコンテナは UTC。10:00 開始、15:00 終了、休憩 12:00、休憩終了 13:00 は、`01:00:00`、`06:00:00`、`03:00:00`、`04:00:00` で保存されている。

表示は、APIが返した瞬間を日本時間にするだけにした。9時間足す読み方と、3時間引く読み方はやめた。利用履歴、本人記録、支援記録、今日の在宅、概要、勤怠がこの読み方。決まりは `doc/時間の取り扱い.md`。確認の手順は `doc/202611作業/202611バックエンドあて依頼/本番サーバーのタイムゾーン確認.md`。
