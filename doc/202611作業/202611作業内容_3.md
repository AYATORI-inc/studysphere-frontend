## 利用者の学習画面

これまでの学習画面は `/student/old-enhanced-learning` に退避した。旧ダッシュボードの「学習開始」「続きから」は、こちらへ行く。指導員の旧プレビュー、テスト結果、レッスン一覧からの学習再開も、退避した画面のままである。

新しい学習画面は `/student/enhanced-learning`。新しいダッシュボードとカリキュラム詳細は、こちらを開く。

ヘッダーは他の利用者画面と同じである。ダッシュボードやレッスン一覧へのメニューは置かず、その場所にカリキュラム名とレッスン名を出す。

左はセクション一覧。左端から始まり、高さは画面いっぱい、中は縦にスクロールする。並びは次のとおり。

- セクション名
- その下に字下げした「テスト」
- 最後に「レッスンテスト実施」

いま開いているセクションは白くなり、「学習中」と出る。前回開いた場所には「前回の位置」が残る。セクション名、テスト、レッスンテストは、枠のあるボタンである。一番下の「<」で一覧を閉じ、閉じているときは「>」で開く。

最初に出るのは、選んでいるセクションの動画である。上のボタンで切り替える。

| ボタン | 中身 |
|---|---|
| 動画 | そのセクションの映像 |
| 教科書 | 既存の Markdown 表示。見出し、目次、本文 |
| AI質問 | 質問欄。送信は `/api/ai/assist` |
| 動画・教科書並べて表示 | 映像と教科書を左右に並べる |
| 課題の提出 | 課題があるレッスンだけ、これまでの ZIP 提出を開く。無いレッスンでは「このレッスンに課題はありません。」 |

教科書の本文は `GET /api/test/learning/extract-text`。JSON の `data.text` を読む。プレーンテキストのまま返す場合も、その本文を出す。

この画面を開いただけでは、最終アクセスは更新しない。テストを開くときだけ、これまでのとおりテストの一時データを消してからセクションテスト、またはレッスンテストへ進む。

## カリキュラムパス

一覧は `/admin/curriculum-paths`。画面名の下に「複数のコースをひとつにまとめて、利用者に提供するものです。」と書いてある。パス名、説明、対象者、期間、入っているコース名で探せる。カードを開くと `/admin/curriculum-paths/パスID`。

新規作成ではコースを選ばない。フォームには「作成後、コースを追加してください。」と書いてある。状態の初期値は下書き。

詳細は、カリキュラムパス基本情報とコース一覧である。基本情報の「編集」では、パス名、状態、対象者、期間、説明を直す。保存するときは、入っているコースも一緒に送り直す。コースを省くと、パスからコースが消える。

コース一覧の「コース追加」で、まだ入っていないコースを足す。並びは「上へ」「下へ」で入れ替え、押した時点で保存する。先頭の「上へ」と、末尾の「下へ」は押せない。

「削除ボタンの表示」は2つある。基本情報のほうをオンにすると、パスの「削除」が出る。削除すると一覧へ戻る。コース一覧のほうをオンにすると、各コースに「外す」が出る。確認のあと、残ったコースだけを送り直し、並びを1から振り直す。

## レッスン詳細

レッスン情報の「編集」に「課題あり」を付けた。オンとオフを保存できる。

各セクションの「編集」で、動画の名称、説明、URL、時間をその場で直す。ファイル名は表示だけである。「URLを空にすると、テキストだけ残して動画を外します。」URLを空にして保存すると、紐づけと動画を外し、テキストファイルは残す。テキストだけのセクションにURLを入れると、動画を作ってから紐づける。動画だけではセクションを作れない。

## 事業所詳細

利用者一覧に「利用者トークン」と「本日有効」を足した。トークンは利用者のログインコードで、無いときは「未設定」である。本日有効は、その日の一時パスワードである。出ていればパスワード、有効か期限切れか、期限を出す。無いときは「有効化」、あるときは「再発行」。発行は `POST /api/users/利用者ID/issue-temp-password`。アカウントのパスワードは置き換えない。

カリキュラムパスの一覧を、コースの情報の上に置いた。並びは、基本的な情報、カリキュラムパス、コースの情報、指導員一覧、利用者一覧。件数は「利用できる N件 / 全M件」。利用できるのは、公開中で、中のコースがこの事業所で無効になっていないパスである。下書き、非公開、公開中でも無効なコースを含むものは、それぞれ下書き、非公開、無効と出す。パス名はカリキュラムパスの詳細へ行く。

利用者ごとの本日有効は、この一覧で足りることにした。事業所をまたいだ一括発行、期限の時刻指定、お知らせ送信は、旧ダッシュボードの一時パスワード管理に残している。指導員のパスワード発行と変更要求は、指導員詳細のパスワード管理のままである。
