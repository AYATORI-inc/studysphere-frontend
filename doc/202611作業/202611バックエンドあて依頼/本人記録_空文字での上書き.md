# 本人記録のテキストを空文字で上書きする

利用履歴の本人記録（`UserInputModal`）で、文章を消して保存しても、元の文章が残る。画面は空文字を送っている。`RemoteSupportController.updateDailyReport` が空文字を更新対象から外している。

呼び出しは既存のまま。

```http
PUT /api/remote-support/daily-reports/:id
Authorization: Bearer <既存の指導員トークン>
Content-Type: application/json
```

## 変えること

`scripts/remoteSupportController.js` の `updateDailyReport`。`isValidValue` は空文字と空白だけを無効にしている。

```javascript
return value !== undefined && value !== null && value !== '' && String(value).trim() !== '';
```

キーがリクエストにあるテキスト項目は、空文字も空白だけも、空文字 `''` で上書きする。キーが無い項目は、今どおり更新しない。

対象は次のカラム。

`condition_note`、`work_note`、`work_result`、`daily_report`、`task_content`、`support_content`、`support_method_note`、`advice`、`recorder_name`

`work_note` は NOT NULL なので、NULL にはしない。空文字にする。

体温、体調、睡眠時間、支援方法、打刻は今回変えない。打刻は、送られた `null` を NULL にする今の動きのまま。

## 確認

作業予定に文章がある記録で、その欄を空にして保存する。再取得すると `work_note` は `''` で、他の欄は送った値のまま残る。
