# 利用者一覧は、現在学習コースとその進捗だけ返す

対応済み。利用者管理の一覧は、各利用者の `currentCourse.title` を「現在学習コース」に、`currentProgress` を「進捗状況」に出す。`currentCourse` が null のときは未設定とし、全コースを混ぜた `progress` では埋めない。

利用者管理（`/instructor/students`）の一覧は、「現在学習コース」とそのコースの進捗だけを出す。コースの一覧とタグは、この列には出さない。

呼び出しは今のまま。

```http
GET /api/satellites/:satelliteId/users
Authorization: Bearer <既存の指導員トークン>
```

## 今の動き

`scripts/userController.js` の `getSatelliteUsers` は、利用者の有効なコースを全部 `courses` に入れ、進捗はそれらの全レッスンを混ぜて計算している。カリキュラムパスも `courses` に混ざる。

## 変えること

各利用者に `currentCourse` と `currentProgress` を足す。今の `courses`、`tags`、`progress` は残す。

現在学習コースは、次の順で1つに決める。

1. `user_lesson_progress.status = 'in_progress'` のレッスンのうち、`COALESCE(last_accessed_at, updated_at)` が最新のレッスンが属するコース。`getCurrentLesson` と同じ選び方。
2. 進行中が無いときは、`user_courses.status = 'active'` かつコースが有効で、そのコースのレッスンがまだ全部完了していないもののうち、`courses.order_index` が小さいコース。
3. 該当が無ければ `currentCourse` は `null`、`currentProgress` は `0`。

カリキュラムパスは現在学習コースにしない。

`currentProgress` は、そのコースのレッスンだけを見る。完了は 1、進行中は 0.5、未開始は 0。今の進捗式と同じ。全コースを混ぜない。

```json
{
  "currentCourse": { "id": 12, "title": "ITリテラシー・AIの基本" },
  "currentProgress": 40
}
```

## 確認

進行中のレッスンがある利用者は、そのレッスンのコース名と、そのコースだけの進捗が返る。進行中が無く未完了のコースがある利用者は、並びが若いそのコースが返る。コースが無い利用者は `currentCourse` が `null` で、`currentProgress` は `0`。
