# 在宅利用者と日次記録の取得に、期間と利用者の絞り込みを足す

対象は既存の次のAPI。URLは変えない。

```http
GET /api/users/satellite/:satelliteId/home-support-users-with-records
```

実装は `scripts/userController.js` の `getSatelliteHomeSupportUsersWithDailyRecords`。ルートは `routes/userRoutes.js`。

いま受け取っているクエリは `instructorIds` と `date`。`date`（`YYYY-MM-DD`）があるとその日の `remote_support_daily_records.date` だけを結合する。`date` がないと、その拠点の在宅利用者に紐づく日次記録を日付の制限なく結合する。写真（`webcam_photos`、`screenshots`）も含まれるため、履歴が長いと応答が重くなる。

## 足すクエリ

いずれも任意。フロントの `src/utils/api.js` の `getSatelliteHomeSupportUsersWithDailyRecords` は、第4引数を渡したときだけ次の名前で付ける。

| 名前 | 例 | 意味 |
|---|---|---|
| `startDate` | `2026-11-01` | 期間の開始日。`YYYY-MM-DD` |
| `endDate` | `2026-11-19` | 期間の終了日。`YYYY-MM-DD` |
| `userId` | `123` | 絞る在宅利用者のID。ログイン中の指導員ではない |

`userId` は文字列で届くことがある。数値に直す。

## 既存の呼び方は変えない

次の画面は、いまも `date` だけ、またはクエリなしで呼んでいる。これらの応答の形と中身は変えない。写真も今までどおり返す。

- 本日利用状況、在宅支援メイン: `date` に今日
- 利用履歴: `date` に選んだ日
- 在宅支援の利用者タブ、ダッシュボードの警告: 日付なし

`date` が付いているときは、期間の指定があっても今までどおりその1日だけを対象にする。

## 新しい指定のときの動き

`date` がなく、`startDate` と `endDate` が両方あるとき、日次記録はその期間（両端を含む）だけを結合する。このとき写真列は返さない。応答の形は維持し、`webcam_photos` と `screenshots` は空配列にする。期間指定で全履歴の写真を読まないため。

`userId` があるときは、その在宅利用者の行だけにする。拠点の条件（在宅利用者、有効、その拠点）は今までどおり先にかける。該当しなければ `success: true` で `data` は空配列。

`startDate` と `endDate` の片方だけ、日付の形式が違う、開始日が終了日より後、`userId` が数値でない、のいずれも 400。`message` は日本語。

`instructorIds` の意味は変えない。

## 応答

成功は今までどおり `{ "success": true, "data": [ ... ] }`。失敗は `{ "success": false, "message": "..." }`。

認証と権限は、このAPIの現状に合わせる。
